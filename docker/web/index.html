Megane Diag

Diagnostica in sola lettura per Renault Megane IV · R-Link2

Android APK

App per lo schermo R-Link2 via Android Auto. Dati live, codici guasto in italiano, correlatore CAN. Richiede un telefono Android.

Scarica APK Istruzioni
Installazione fuori dal Play Store: attiva "origini sconosciute" in Android Auto (Impostazioni → tocca 10 volte "Versione" → menu sviluppatore).

macOS / Linux / Windows JAR

App desktop con grafico tensione e correlatore. Richiede Java 17 o superiore.

Scarica JAR

Avvio: java -jar megane-desktop.jar

Hardware necessario OBD2

Un adattatore OBD2 Bluetooth per leggere l'auto.

  1. vLinker MC+ Bluetooth (~45 €) — consigliato, NON la versione WiFi.
  2. Per il logger CAN avanzato: interfaccia SLCAN (canalyze / CANable) via USB.

Cosa fa e cosa non fa

Legge soltanto. Non scrive sulle centraline, non invia frame sul bus, non modifica il firmware R-Link2. Nessuna funzione che alteri la calibrazione del veicolo o le emissioni.
